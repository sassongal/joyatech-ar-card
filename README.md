# JoyaTech AR Business Card

AR business card — scan the physical card to see a 3D holographic experience.

## Files

- `business-card-design.html` — Print-ready card design (front + back)
- `src/index.html` — 8th Wall AR experience  
- `preview-ar-experience.html` — Browser preview (no camera needed)
- `src/targets/joyatech-card-target.js` — Image target config

## Setup

```bash
npm install
npm run target   # Process card image as image target
npm run serve    # Dev server on port 8080
```

## Stack

- 8th Wall Open Source (MIT) — WebAR engine
- A-Frame 1.5 — 3D/VR framework
- Three.js — Custom 3D components
